# bench-text-v1-en — TTS benchmark text dataset

A length-controlled English text corpus for performance (load) testing of the
TTS server. **Dataset name: `bench-text-v1-en`.** Benchmark result JSON should
carry `dataset: "bench-text-v1-en"` in its metadata; any material change to this
corpus requires bumping the version (`-v2`, …).

> These texts exist to drive the server under controlled load. They are **not**
> a model-quality evaluation set. All text is drawn from public-domain / CC0
> sources and may be stored verbatim in the repo.

## Why length-controlled

TTS synthesis cost is strongly correlated with input length. For a concurrency
sweep (1/2/4/8) the **only** independent variable must be concurrency, so every
input in a bucket falls in one tight word-count window. Word counts are measured
by whitespace splitting (`len(text.split())`).

| Bucket | File | Items | Word count | ≈ Audio length |
|---|---|---|---|---|
| main (HTTP + WS matrix) | `texts_main.jsonl` | 60 | 35–55 words | ~12–20 s at ~165 wpm |
| long ( soak / overflow ) | `texts_long.jsonl` | 10 | 300–350 words | ~2–2.5 min |

Benchmarks rotate through the bucket's texts so the same length distribution is
exercised at every concurrency level.

## Main bucket composition (60)

| Source | Count | Notes |
|---|---|---|
| Harvard / IEEE sentences | 28 | 3–5 phonetically-balanced sentences concatenated per item (statements) |
| LJ Speech (normalized) | 18 | Coherent multi-sentence passages; supplies the `?` (question) items |
| LJ Speech (original column) | 8 | Retains **Arabic digits** (years/dates/amounts, e.g. `1455`, `1462`) |
| LJ Speech base + synthetic `555-01xx` clause | 6 | Fictitious NANP phone numbers to exercise numeral rendering |

Coverage across the 60: **6** items contain a question, **14** contain an Arabic
digit (8 natural + 6 phone), all contain common punctuation.

## Cancel plan (`cancel_plan.json`)

For the concurrency-4 mixed-cancel run, 30% of main ids (= **18**) are marked
cancel. Selection rule: **main id numeric suffix `% 10 ∈ {2,5,8}`** → exactly 18
of 60, deterministic and reproducible. The TTS server exposes **no explicit
cancel message**; "cancel" means the client disconnects mid-stream. The benchmark
client opens the request, then closes the connection after `cancel_after_ms`
(500 ms). Items whose id is in `cancel_ids` should be assigned to cancel slots.

## Long bucket composition (10)

Ten coherent 300–350-word paragraphs from **"A Short History of the World"** by
H. G. Wells, 1922 (Project Gutenberg #35461, public domain). All ten contain
Arabic digits (dates, magnitudes). `source` field:
`"A Short History of the World (Project Gutenberg #35461, 1922, public domain)"`.

### Build notes / deviations (per the unreachable-source fallback rule)

- **Mozilla Common Voice (CC0)** was intended as the Arabic-digit source for the
  main bucket but was **not reachable** from the build environment
  (`huggingface.co` is blocked; the `hf-mirror.com` mirror exposes no usable
  parquet ref, and the mirror's `refs/convert/parquet` revision is invalid).
  Arabic-digit coverage is therefore drawn from the **LJ Speech *original***
  transcription column, which retains literal digits — same dataset, public
  domain, same allowed source label (`ljspeech`).
- LJ Speech spans several books; only **neutral non-fiction** books are used
  (printing history, science, ancient history, and U.S. presidential "Fireside
  Chats" — public domain as U.S. government works). Excluded: a prison
  chronicle, a cookbook, and the Warren Report (assassination) — kept out so the
  corpus stays on benign topics.
- The **6 phone numbers** (`555-01xx`) are **synthetic**: the NANP reserves
  `555-0100`–`555-0199` for fictitious use. They are appended as standalone
  sentences to public-domain base passages purely to exercise numeral-to-word
  rendering. No real phone numbers or personal data appear anywhere.

## Reproducibility

The corpus is generated by a deterministic builder (no randomness; word counts
enforced per item). Re-running it against the same cached source corpora
reproduces byte-identical output, so the committed files are the canonical
artifact. Integrity is verified by `validate.py`.

```bash
uv run python benchmarks/data/validate.py        # exit 0 == all checks pass
```
